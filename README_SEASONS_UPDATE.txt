GOSPER GLOBAL eFOOTBALL LEAGUE — CONTINUOUS SEASONS UPDATE

New season workflow:
1. Admin signs in.
2. Dashboard now has "Start New Season".
3. Clicking it archives the current season and creates Season N+1.
4. Previous season data is not deleted.
5. Promotion/relegation is applied:
   - Championship #1 -> Premier League
   - Championship #2 -> LaLiga
   - Championship #3 -> Serie A
   - Championship #4 -> Bundesliga
   - #8 from each major league -> Championship
6. All active members/players are copied into the new season with the same club.
7. The four league champions are stored in Hall of Fame.
8. The previous season's top four from each major league (16 total) are stored as the new season's UCL qualifiers.
9. Fresh home/away domestic fixtures are generated automatically.
10. UCL groups (4 groups of 4) and home/away group fixtures are generated automatically.
11. Season themes continue to rotate so seasons can have different visual themes.

Important:
- Old fixtures/results/players/teams remain under their original seasonId.
- Season selector can open any historical season.
- The Start New Season action requires an authenticated admin.
- This ZIP contains the actual modified files from the Seasons Notebook project.
